# Implementierungsplan: M3.1 — M3 follow-ups

Status: Draft — finalized after the M3b report · 2026-10-05 · Author: architect
Basis: M3b report (sections 4–7), architecture v1.6 §9–§10

Binding language: **MUST** / **MUST NOT** / **SHOULD** / **MAY**.

## 1. Goal
Close the M3 review findings that affect security and production behaviour.

## 2. Findings to address (from M3b)
1. **Restricted commands can be widened:** `pkg/sudoers.ValidateCommand` accepts sudo regular expressions
   (`^…$`, sudo ≥ 1.9.10) and glob characters (`*`, `?`, `[`) in arguments, e.g. `/usr/bin/systemctl ^.*$`.
2. **Authentik device-authorization throttle:** default 20 per hour per client address; many devices behind one NAT
   address will be refused (`slow_down`) at login time.
3. **Deny file absent when empty:** `pam_listfile` logs "Couldn't open /etc/paddock/login-deny" at every
   authentication.
4. **apt:** the agent updates only the Himmelblau source; stale Ubuntu lists make dependency installs fail.
5. **Architecture §10.1** still says privileged groups contain exactly `{paddock-admin}`; M3a/M3b use the
   organization's `break_glass_accounts` list until the managed local admin exists (M4).

## 3. Binding decisions (to be confirmed when finalizing)
1. Restricted commands MUST NOT contain `^`, `$`, `*`, `?`, `[`, `]` anywhere (422 `invalid_command`, message names
   the character); existing profiles violating it are reported in the portal and their entries are omitted from
   bundles with an audit event until fixed. Same check in `pkg/sudoers` on the device (defence in depth).
2. Production Compose sets `AUTHENTIK_THROTTLE__PROVIDERS__OAUTH2__DEVICE` from a Paddock variable
   `PADDOCK_DEVICE_LOGIN_THROTTLE` (default `600/hour`), documented in `docs/operations/device-login.md` with the NAT
   consideration.
3. The agent always writes `/etc/paddock/login-deny` (empty when nobody is locked); a missing file remains fail safe.
4. On a dependency failure during the Himmelblau install the agent runs one full `apt-get update` and retries once.
5. Architecture §10.1 wording updated by the architect.
