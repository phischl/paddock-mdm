- The audit index numbers every event per organization in the order the audit writer committed it (`commit_seq`), so
  consumers can read the audit trail without skipping late events from offline devices and can detect gaps. The
  upgrade numbers the existing events once; plan about 1.5 minutes per million audit events, during which the audit
  writer pauses and its queue holds new events (`docs/operations/capacity.md`). An event that a concurrent writer
  indexed first now fails the batch and leads to a redelivery instead of being skipped.
