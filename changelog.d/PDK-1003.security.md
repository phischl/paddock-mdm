- Agent release packages are checked against their own control file: the upload, the host command
  (`paddock-server admin agent-release`) and the GitHub import refuse a package whose `Package`, `Version` or
  `Architecture` differs from what it is stored as (422 `package_name_mismatch`, `package_version_mismatch`,
  `package_arch_mismatch`), so a validly signed package can no longer be stored under another package's name or, for
  `fleet-osquery`, under another fleetd version. `Version` is the release version with `~` for the pre-release
  separator (`0.1.0~alpha.11`). A control archive in another compression than gzip or zstd is refused with 415
  `unsupported_control_compression`. Releases already stored are not verified again. Closes residual risk RR-136.
