- Action records keep their own times (PDK-635, ADR 0032 amendment 2026-10-31): the database bounds the finish time
  of an action to its own clock, never earlier and at most five minutes later, whatever time the finishing or inserting
  statement wrote, so no database role can backdate a finish to have the retention round delete the record early; a
  started action changes only by being finished, and its ID, code, actor, source, correlation ID, start time and its
  organization can no longer be changed by any role. A started action whose start time lies more than five minutes off the database clock
  is refused, so keep the control plane's and the database's clocks synchronised. Schema: migration `00084`.
