- Action records keep their own times (PDK-635, ADR 0032 amendment 2026-10-31): the database now sets the finish time
  of an action when it is finished, whatever time the finishing statement wrote, so no database role can backdate a
  finish to have the retention round delete the record early; an action's ID, code, actor, source, correlation ID and
  start time can no longer be changed by any role. Schema: migration `00084`.
