- `sudo`, `su` and other commands that authenticate no longer print the directory login service's connection errors
  while the agent installs packages. The agent now has systemd remove the login service's socket files whenever the
  service stops, so authentication falls back to local accounts silently during the pause.
- A `reset` removal now also takes the `himmelblau` entries out of `/etc/nsswitch.conf`, together with the login
  service's leftover socket files. A line in `/etc/nsswitch.conf` that was edited beyond the package's own addition is
  left as it is and logged in the removal's journal.
