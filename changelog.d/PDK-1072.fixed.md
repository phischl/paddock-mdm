- The compiler no longer holds one database transaction for a whole organization's compile. It reads the inputs in
  one short consistent snapshot, renders the bundles outside it and writes the results in short batches, so a large
  organization (70 000 devices) no longer blocks an organization deletion for minutes. A device another compile
  changed in the meantime is compiled again; metric `paddock_compiler_bundles_total` counts these with
  `result="conflict"`.
