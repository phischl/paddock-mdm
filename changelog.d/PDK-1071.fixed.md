- An organization deletion no longer waits for minutes at its step `devices` while the worker refreshes the device
  cache of a large organization. The refresh read every identity key of an organization in one database transaction
  whose cached query plan could join every key with every device: more than 10 minutes and a busy CPU core at 70 000
  devices, every minute. It now reads the keys in pages of 2 000 by device, each page in its own transaction of a few
  milliseconds, with a query whose plan cannot degrade that way, and writes Valkey only after each page committed.
