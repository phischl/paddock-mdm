- An upgrade after a rollback no longer leaves unused organization-deletion users in the bundled object store: the
  rollback keeps the deletion's key files, the bucket bootstrap keeps exactly one user per deletion policy (the one
  whose key is in the key file) and removes every other holder after the current user is verified, and
  `./paddock check --online` fails when a deletion policy is held by more than one user or by an unknown key.
