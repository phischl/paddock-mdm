- Third-party components move to their latest patch and minor releases: Fleet 4.96.0, Authentik 2026.8.6, OpenBao 2.7.3 (security fixes for forwarded requests and alias handling), RabbitMQ 4.4.1, Valkey 9.2.0 and Himmelblau 4.0.9 (device login). The images are exchanged on the next `./paddock upgrade`; OpenBao starts sealed after the exchange, so have the custodians ready or automatic unseal on. Devices receive Himmelblau 4.0.9 with their current agent at the next login drift check. The AWS CLI image used by the bucket bootstrap and restore commands moves to 2.42.2 and the RustFS admin CLI to 0.1.38; `./paddock pull` does not fetch the AWS CLI image, so on a host without registry access load the new `AWS_CLI_IMAGE` of `versions.env` by hand (`docker save` on a connected host, `docker load` here) before those commands next run. An RDB file written by Valkey 9.2 does not load in 9.1, so a rollback to the previous release needs a fresh Valkey volume.
