- The mutual watch now reports a stopped Paddock agent also when the device keeps checking in, which happens when
  another program uses the device's credentials. The event `device.tamper_agent_not_running` gains the optional
  parameters `failing_since` and `evaluated_at`; its code and syslog MSGID are unchanged. After the upgrade, every
  active device whose `paddock_agent_running` policy has been failing for a while although it checks in is reported
  once, about 25 minutes after the first inventory sync; expect this one-time wave of events and tamper findings.
