- Software: a catalog entry can require approval. Users of an available application then ask for it on their device,
  and an organization administrator approves or denies the request with a reason under
  `/api/v1/software-requests`. An approval reaches the device with its next bundle. A request with no decision expires
  after 30 days; open requests expire once the entry no longer requires approval, and open and approved ones once the
  entry has no available assignment left. Agents before 0.1.0-alpha.10 never receive an application that requires
  approval. Open requests appear in the attention list as `software_requests_open`. A new request emits the
  notification code `software_request.opened`; it is not in the security preset. The declarative `software_catalog`
  section carries `approval`. The user's request and the approval flow on the device follow with the agent and the
  portal.
