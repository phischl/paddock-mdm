- The step `broker` of `./paddock upgrade` (`./paddock bootstrap broker --import`) no longer fails on RabbitMQ 4.4,
  whose command-line tool cannot read the definitions from standard input: the broker container now keeps them in a
  private temporary file for the import and removes it right after. `./paddock bootstrap broker` repeats its
  comparison for a few seconds while the broker still applies the import.
