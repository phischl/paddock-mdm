- `./paddock bundles prune [--keep N] [--yes]` removes the superseded configuration bundle versions from the
  control plane's file store, keeping the newest N (default 2, at least 2) per device and anything younger than 10
  minutes. Without `--yes` it only prints how many it would remove. A run with `--yes` is recorded in the platform
  audit log as `platform.bundle_versions_pruned`; if a run is interrupted, the event counts every key it did not
  delete as failed. The sizing guidance in `docs/operations/capacity.md` now counts every stored bundle version.
