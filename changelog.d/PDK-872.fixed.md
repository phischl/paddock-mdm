- After a restore or a rollback, devices again receive a newer configuration bundle right away, also when an earlier
  restore had already raised the bundle sequence (for example a restore after an upgrade, then a rollback). The raise
  is now computed from the highest sequence the stack held before it went down. A disaster restore uses the new
  high-water file `bundle-seq/high-water` in the bundle directory, which the backup role updates after every successful
  round. Without either source the restore warns and raises by the previous fixed 1,000,000.
