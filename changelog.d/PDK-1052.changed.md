- A new sign-in setup link ends every older link of the account, including the password link of a new user: only
  the link handed over last works. The audit events `user.enrolment_link_created`, `platform.enrolment_link_created`
  and `user.created` record how many older links were ended (`previous_links_revoked`). When the older links cannot
  be ended, no new link is issued and the request answers 502 `upstream_unavailable`.
- Accounts from the organization's identity source set up only their passkey with a sign-in setup link; the link asks
  for a password only for an account Paddock created that has none.
- The host command `admin enrolment-link` also lets a platform administrator created by hand in the identity provider
  set the password with the link, unless the account is connected to an upstream identity source; then the link sets
  up only the passkey and the command says so. Its audit event records the decision (`passkey_only`).
